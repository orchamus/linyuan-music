# 接口文档

- 服务地址：`http://localhost:8080`
- 统一响应：`{ "code": 0, "message": "操作成功", "data": ... }`，`code = 0` 表示成功
- 鉴权：除登录 / 注册 / 公开列表接口外，请求头需带 `Authorization: Bearer <token>`
- 分页参数：`pageNum`（页码，从 1 开始）、`pageSize`（每页条数），返回 `{ total, items }`

## 一、用户与认证 `/user`

| 方法 | 路径 | 说明 | 鉴权 |
| --- | --- | --- | --- |
| GET | `/user/sendVerificationCode?email=` | 发送邮箱验证码（Redis 存 5 分钟） | 否 |
| POST | `/user/register` | 注册：username、email、password、verificationCode | 否 |
| POST | `/user/login` | 登录：email、password（8~18 位，数字+字母/符号） | 否 |
| GET | `/user/getUserInfo` | 当前登录用户信息 | 是 |
| PUT | `/user/updateUserInfo` | 修改资料（multipart，可带 avatar 文件） | 是 |
| POST | `/user/logout` | 退出登录（删除 Redis 会话） | 是 |
| DELETE | `/user/deleteAccount` | 注销账号 | 是 |

## 二、歌曲 `/song`

| 方法 | 路径 | 说明 | 鉴权 |
| --- | --- | --- | --- |
| POST | `/song/getAllSongs` | 分页查询歌曲，body：`{pageNum, pageSize, songName?, artistName?, album?}` | 否 |
| GET | `/song/getRecommendedSongs` | 推荐歌曲（20 首，Redis 缓存） | 否 |
| GET | `/song/getSongDetail/{id}` | 歌曲详情（含歌词、点赞状态） | 否 |

## 九、静态文件

本地存储模式下上传的文件通过 `GET /files/**` 访问，例如：

```
http://localhost:8080/files/songCovers/track-01.png
http://localhost:8080/files/songs/track-01.mp3
```

## 十、常见错误码

| HTTP | code | 说明 |
| --- | --- | --- |
| 200 | 0 | 成功 |
| 200 | 1 | 业务失败（message 为具体原因，如“密码错误”） |
| 401 | - | 未登录 / 会话过期 |
| 403 | - | 无权限访问该路径 |
| 500 | - | 服务端异常（统一由 `GlobalExceptionHandler` 包装） |
