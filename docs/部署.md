# 部署文档

## 一、环境要求

| 组件 | 版本 | 是否必须 |
| --- | --- | --- |
| JDK | 17+ | 是 |
| Maven | 3.8+（项目自带 `mvnw`，可不装） | 否 |
| MySQL | 8.0+ | 是 |
| Redis | 6+ / 7 | 是（登录会话、验证码、缓存） |
| Node.js / pnpm | 18+ / 9+ | 前端构建需要 |
| MinIO | 任意版本 | 否（默认本地磁盘存储） |

## 二、本地开发

### 1. 数据库

```bash
mysql -u root -p -e "CREATE DATABASE linyuan_music CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;"
mysql -u root -p --default-character-set=utf8mb4 linyuan_music < sql/linyuan_music.sql
```

### 2. Redis

```bash
redis-server --port 6379
# 或使用 Docker
docker run -d --name linyuan-redis -p 6379:6379 redis:7
```

### 3. 后端配置

```bash
cd linyuan-music-backend
cp linyuan-music-server/src/main/resources/application-dev.example \
   linyuan-music-server/src/main/resources/application-dev.yml
```

编辑 `application-dev.yml`：填写 MySQL 账号密码、Redis 地址；`storage.type` 保持 `local` 即可开箱即用；邮箱配置可留空（仅注册 / 找回密码时使用）。

### 4. 启动

```bash
# 后端（在 linyuan-music-backend 目录下执行，保证 uploads/ 路径正确）
./mvnw spring-boot:run -pl linyuan-music-server

# 前端
cd ../linyuan-music-client && pnpm install && pnpm dev   # http://localhost:8090
cd ../linyuan-music-admin && pnpm install && pnpm dev    # http://localhost:8089
```

### 5. 演示账号

- 管理端：`admin` / `abc12345`
- 用户端：`linyuan@example.com` / `abc12345`

## 三、Docker 一键启动依赖

仓库根目录提供 `docker-compose.yml`，只包含 MySQL 与 Redis：

```bash
docker compose up -d
# 首次启动会自动创建 linyuan_music 库并导入 sql/linyuan_music.sql
```

## 四、生产部署

### 1. 后端

```bash
cd linyuan-music-backend
./mvnw clean package -DskipTests
cp linyuan-music-server/target/linyuan-music-server-*.jar /opt/linyuan-music/
```

运行（建议用 systemd 或 supervisor 托管）：

```bash
cd /opt/linyuan-music
java -jar linyuan-music-server-0.0.1-SNAPSHOT.jar \
  --spring.profiles.active=prod \
  --linyuan-music.datasource.url="jdbc:mysql://127.0.0.1:3306/linyuan_music?useUnicode=true&characterEncoding=utf-8&useSSL=false&serverTimezone=Asia/Shanghai" \
  --linyuan-music.datasource.username=root \
  --linyuan-music.datasource.password=****** \
  --linyuan-music.redis.host=127.0.0.1 \
  --linyuan-music.storage.local-dir=/opt/linyuan-music/uploads \
  --linyuan-music.storage.public-base-url=https://music.example.com/files
```

> 生产环境建议把 `linyuan-music.storage.type` 切换为 `minio`，或把 `uploads/` 挂载到独立磁盘并交给 Nginx 直接托管。

### 2. 前端

```bash
cd linyuan-music-client && pnpm install && pnpm build   # dist/
cd linyuan-music-admin  && pnpm install && pnpm build   # dist/
```

将两个 `dist/` 分别部署为静态站点，并把 `VITE_APP_BASE_API` 指向后端地址：

```bash
# .env.production
VITE_APP_BASE_API = 'https://api.example.com'
```

### 3. Nginx 参考配置

```nginx
server {
  listen 80;
  server_name music.example.com;

  # 用户端
  location / {
    root /var/www/linyuan-music-client;
    try_files $uri $uri/ /index.html;
  }

  # 管理端
  location /admin/ {
    alias /var/www/linyuan-music-admin/;
    try_files $uri $uri/ /admin/index.html;
  }

  # 后端接口
  location /api/ {
    proxy_pass http://127.0.0.1:8080/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
  }
}
```

## 五、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 页面图片 / 音频 404 | `uploads/` 路径是按后端**启动目录**解析的，请在 `linyuan-music-backend/` 下启动，或显式指定 `--linyuan-music.storage.local-dir` |
| 登录后接口返回“会话过期” | Redis 未启动或数据库被重置导致 token 不在 Redis 中，重新登录即可 |
| `Could not resolve type id 'com.xxx.Result'` | Redis 中残留了旧版本序列化的缓存，执行 `redis-cli -n 1 FLUSHDB` 后重试 |
| 管理端登录提示密码错误 | 数据库未导入示例数据，或账号被修改；可执行 `sql/linyuan_music.sql` 重新导入 |
| 上传文件失败 | MinIO 模式下检查 endpoint / accessKey / bucket 与匿名读权限；本地模式检查目录写权限 |
