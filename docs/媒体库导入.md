# 导入完整曲库（501 首音频 + 423 张封面）

仓库自带的是**示例数据集**（10 首示例音频 + 生成封面），方便 clone 后零依赖跑起来。
如果要使用完整曲库（真实音频与封面，约 3.7 GB），按下面的步骤导入。

> 完整媒体包不入 Git 仓库（3.7 GB 远超 GitHub 单文件/仓库限制），只提供导入脚本与对应的 SQL。

## 1. 准备媒体包

拿到 `vibe-music-data.zip`（约 3.7 GB），目录结构为：

```
songs/        501 个 mp3
songCovers/   271 个封面（文件名形如 <uuid>-blob，无扩展名）
artists/      123 张歌手头像
playlists/    17 张歌单封面
banners/      10 张轮播图
users/        2 张用户头像
```

## 2. 一键导入

```powershell
cd linyuan-music-backend
pwsh ../scripts/import-media.ps1 -Zip "D:\BaiduNetdiskDownload\vibe-music-data.zip" -Target "D:\linyuan-media"
```

脚本会做三件事：

1. 解压到 `-Target` 目录；
2. 给 `-blob` 文件按文件头（PNG/JPEG/WebP/GIF）补上正确扩展名，否则静态服务无法返回正确的 `Content-Type`；
3. 把 `sql/linyuan_music_full.sql` 导入数据库（该文件中的媒体地址已指向 `http://localhost:8080/files/`）。

## 3. 用媒体目录启动后端

```powershell
$env:DASHSCOPE_API_KEY="sk-xxx"
$env:STORAGE_DIR="D:/linyuan-media"
java -jar linyuan-music-server/target/linyuan-music-server-0.0.1-SNAPSHOT.jar
```

启动日志出现下面这行说明生效：

```
本地文件映射: /files/** -> file:///D:/linyuan-media/
```

## 4. 验证

```powershell
curl -I "http://localhost:8080/files/songCovers/645b6c4c-c53c-4bc7-9d68-aee20fde416f-blob.png"
# HTTP/1.1 200 OK  Content-Type: image/png

curl -I "http://localhost:8080/files/songs/f9580a5c-39a6-4950-8bc0-18d8a8e3612c-Aaron%20Carter%20-%20Fool's%20Gold.mp3"
# HTTP/1.1 200 OK  Content-Type: audio/mpeg
```

浏览器打开用户端，曲库里的封面与播放应全部正常。

## 说明

- `STORAGE_DIR` 是后端 `linyuan-music.storage.local-dir` 的快捷覆盖；不设置时默认 `./uploads`（即仓库内示例数据）。
- 媒体目录可以放在任意磁盘，建议不要放在仓库目录内，避免误提交。
- 重新导入或换歌单后，记得调用 `POST /rag/rebuild` 重建知识库索引。
